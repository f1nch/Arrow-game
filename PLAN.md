# Number Arrows — Remake Plan

A remake of **Amaze GO!** (tap arrows to slide them off the board) where every
level's board is shaped like its own number. Level 7 is a "7" made of arrows,
level 42 is a "42", and so on.

## 1. Core gameplay (same as the original)

- The board is a grid. Each filled cell holds an arrow pointing up, down, left or right.
- Tap an arrow. If nothing is in its way, it flies off the board.
- If another arrow blocks it, it bumps back and you lose a heart (3 hearts per level).
- Clear every arrow to win. Lose all hearts and you retry the level.
- Extras: a hint (highlights one arrow that can move) and undo (optional).

## 2. The twist: the level is its number

1. Turn the level number into a string, e.g. `"42"`.
2. Draw each digit from a small pixel font (5 wide × 7 tall per digit, 1 empty column between digits).
3. Every "on" pixel becomes one arrow cell. Everything else is empty.
4. Every level uses the same stroke thickness (2 cells), so bigger numbers
   mean bigger boards. Pinch to zoom and drag to pan when cells get small.
5. Difficulty also grows through how arrows are placed (see below):
   later levels have longer chains of arrows that block each other.

## 3. Making every level solvable

Arrow directions are generated by "peeling" the shape from the outside in:

1. Start with all cells of the number shape.
2. Find cells that can see the board edge in some direction with nothing in the way.
   (The outermost cell in any row or column always can, so one always exists.)
3. Pick one at random, give it that direction, and remove it from the shape.
4. Repeat until the shape is empty.

Playing that removal order forward always works, so every level is solvable.
To make levels harder, prefer cells and directions whose path crosses more other
arrows. Use the level number as the random seed so each level is always the same.

## 4. Tech stack

- **Web game**: TypeScript + HTML Canvas, built with Vite.
- Works on phones and desktop. It can be installed as a PWA later.
- No backend. Progress is saved in `localStorage`.

## 5. Code layout

```
src/
  font.ts        digit pixel maps (0–9)
  levelGen.ts    number → grid → arrow directions (seeded)
  board.ts       game state, tap logic, win/lose checks
  render.ts      draw grid, arrows, fly-out and bump animations
  input.ts       tap/click handling
  ui.ts          hearts, level label, hint, menu
  main.ts        game loop and level progression
tests/
  levelGen.test.ts  every level 1–500 is solvable and stable for its seed
```

## 6. Build steps

1. **Setup**: Vite + TypeScript project and a test runner (Vitest).
2. **Font + generator**: digit maps, scaling, peel algorithm, seeded RNG, plus tests.
3. **Board logic**: tap, path check, remove or bump, hearts, win/lose.
4. **Rendering**: draw the grid and arrows, scaled to fit the screen.
5. **Juice**: fly-out and bump animations, sounds, a level-complete screen.
6. **Progress**: level select, saved progress, hint button.
7. **Polish**: colour themes, PWA install, playtesting the difficulty curve.

## 7. Later ideas (optional)

- Long arrows that cover several cells (like the original's longer pieces).
- A timed mode or daily challenge (today's date as the number).
- Different fonts as a "skin" for each world.
