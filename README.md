# Number Arrows

An arrow puzzle where every level is shaped like its own number. Tap an arrow
to slide it off the board; if another arrow is in the way you lose a heart.
Clear every arrow to win. Pinch (or scroll) to zoom, drag to pan. See [PLAN.md](PLAN.md) for the design.

```bash
npm install
npm run dev     # play locally
npm test        # level generator + board tests
npm run build   # static build in dist/
```
